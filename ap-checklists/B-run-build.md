- [ ] Pull the payment proposal / selection for `[DATE RANGE]`.
- [ ] **Pull-forward check:** anything due *before the next run* after this one must
      go in this run. Look at due dates against `[NEXT RUN DATE]`, not today.
- [ ] **Discount check:** any early-pay discount expiring before the next run.
      Losing a discount is a silent error — nobody reports it.
- [ ] **Exclusions:** remove anything on hold, in dispute, pending vendor
      verification (Card E), or missing approval.
- [ ] **Credit memos** applied so vendors net correctly rather than paying gross.
- [ ] **Payment method per vendor** is correct `[ACH / check / wire / vcard]`.
      Watch for any vendor set up with more than one active method — that's how the
      same invoice goes out twice by two channels.

      Treasury? Write your actual step here.]`
